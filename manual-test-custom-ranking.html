カスタムランキング404エラー手動テスト

ステップ1: 開発サーバーの確認

開発サーバーが起動していることを確認してください。

npm run dev

http://localhost:3000 にアクセス可能であることを確認

ステップ2: ブラウザの開発者ツールを開く

F12キーを押して開発者ツールを開き、Consoleタブを選択

ステップ3: カスタムランキング作成テスト

  1. カスタムランキングタブをクリック
  2. 「＋ 新しく作成する」ボタンをクリック
  3. タイトル: 「テスト_404確認_${現在時刻}」
  4. ベースジャンル: 音楽を選択
  5. 「次へ」ボタンをクリック
  6. タグ: 「歌ってみた」を入力してEnter
  7. 「保存」ボタンをクリック

ステップ4: 確認ポイント

  • 保存後、画面に「エラー: HTTP 404:」が表示されないこと
  • 作成したカスタムランキングが正しく表示されること
  • コンソールで以下のログを確認: 
    [DEBUG] Setting newlyCreatedRanking:
[DEBUG] Calling onConfigChange after creation:
[DEBUG] Looking for custom ranking:
  • 特に、newlyCreatedRankingMatches が true になっているか確認

ステップ5: 追加テスト

  1. 別のタグ（総合など）に切り替える
  2. 再度作成したカスタムランキングに戻る
  3. エラーが表示されないことを確認

結果の記録

以下の情報を記録してください：

  • 404エラーが表示されたか: [ はい / いいえ ]
  • コンソールのデバッグログの内容
  • その他の異常な動作
