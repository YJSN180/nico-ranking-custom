# カスタムタグランキング - UI設計詳細

## 1. カラーパレットとスタイルガイド

### 1.1 カラー定義（既存のCSS変数を活用）
```css
/* 既存のテーマカラーを継承 */
--primary-color: #5567d8;      /* ライトモード */
--primary-color: #6b7df0;      /* ダークモード */
--primary-color: #1a8cd8;      /* ダークブルーモード */

/* カスタムランキング専用 */
--custom-ranking-card-bg: var(--card-bg);
--custom-ranking-card-border: var(--border);
--custom-ranking-card-hover: var(--surface-hover);
--tag-condition-and: #10b981;    /* 緑 - AND条件 */
--tag-condition-or: #3b82f6;     /* 青 - OR条件 */
--tag-condition-not: #ef4444;    /* 赤 - NOT条件 */
```

### 1.2 レスポンシブブレークポイント
```css
/* 既存の設定に準拠 */
--mobile-breakpoint: 768px;
--tablet-breakpoint: 1024px;
--desktop-breakpoint: 1280px;

/* グリッドレイアウト */
@media (max-width: 768px) {
  /* モバイル: 2列 */
  grid-template-columns: repeat(2, 1fr);
}

@media (min-width: 769px) and (max-width: 1024px) {
  /* タブレット: 3列 */
  grid-template-columns: repeat(3, 1fr);
}

@media (min-width: 1025px) {
  /* デスクトップ: 最大5列 */
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  max-width: 1400px;
}
```

## 3. アニメーションとトランジション

### 3.1 カード表示アニメーション
```css
/* カードの出現アニメーション */
@keyframes cardFadeIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.custom-ranking-card {
  animation: cardFadeIn 0.3s ease-out;
  animation-fill-mode: both;
}

/* スタガーアニメーション */
.custom-ranking-card:nth-child(1) { animation-delay: 0.05s; }
.custom-ranking-card:nth-child(2) { animation-delay: 0.1s; }
.custom-ranking-card:nth-child(3) { animation-delay: 0.15s; }
/* ... */
```

### 3.2 タグ追加/削除アニメーション
```css
/* タグ追加時 */
@keyframes tagAdd {
  from {
    transform: scale(0.8);
    opacity: 0;
  }
  to {
    transform: scale(1);
    opacity: 1;
  }
}

/* タグ削除時 */
@keyframes tagRemove {
  to {
    transform: scale(0.8);
    opacity: 0;
  }
}
```
